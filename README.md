## 📌 关于本书

本书是一份由个人编写的深度学习入门教程，旨在系统梳理知识脉络，希望能够对对深度学习、人工智能以及大语言模型感兴趣的朋友有所帮助。

- **创作状态**：目前全书仍处于撰写阶段。作者平时利用业余时间持续推进，当前更新节奏约为每月 3 ~ 4 个章节。
- **发布平台**：最新文稿内容将优先在小红书平台同步发布（账号：**偷书的孔乙己**）。
- **源码与图件**：全书的 LaTeX 源码同步开源至本 GitHub 仓库。因整理开源不易，书籍相关图件均附带个人水印，敬请理解与包涵。
- **后续规划**：全书完结后将统一整理并开源配套代码实现，后续视情况可能会录制配套的教学讲解与实战视频。



## 🗺️ 知识体系与全书结构

本书构建了一条循序渐进的系统化知识链路：

$$
\textbf{神经网络基础知识} \longrightarrow \textbf{卷积神经网络} \longrightarrow \textbf{自然语言处理} \longrightarrow \textbf{大语言模型}
$$

### 核心章节规划
- **Part 01：神经网络基础知识** —— 感知机、前馈网络、反向传播算法及梯度下降等核心数学机理。
- **Part 02：卷积神经网络（CNN）** —— 卷积原理、感受野、主流经典视觉骨干网络与特征提取。
- **Part 03：自然语言处理（NLP）** —— 词向量表示、循环神经网络、注意力机制与经典序列建模。
- **Part 04：大语言模型（LLM）** —— Transformer 架构精析、预训练机制与大模型微调演进。
- **相关专题拓展**：后续将视进展陆续补充 ViT（Vision Transformer）、GAN（生成对抗网络）以及 Diffusion（扩散模型）等相关主题。
